# parseRuleInfoの判定を反転(#246の21件を解消)

作業日: 2026-07-28。PR #246で見つかった「その他」誤タグ21件(同一クラスの取りこぼしが4回目)を解消するため、`parseRuleInfo`のMMA判定を反転した。

MIXルール・チャレンジルールは指示どおり「今回は触らず据え置く」ため、分類を変更せず現状の除外状態を保つ目的でキーワード化した。

## 2. `parseRuleInfo`の反転実装

`src/lib/mnewsRating/rizinScraper.ts`に`NON_MMA_RULE_PATTERNS`(パターン→ラベルの対応表)を新設し、判定を以下の優先順で行う:

1. ルール行が空文字 → `unknown`(#240から変更なし)
2. "MMA"という文字列が明示されている → `MMA`(最優先。理由は下記「実装中に発見した事故」参照)
3. 上記いずれでもなく、非MMA語(`NON_MMA_RULE_PATTERNS`)に一致する → その語に対応するラベル
4. 上記いずれでもない(非空・非MMA語) → `MMA`(反転後のデフォルト)

### 実装中に発見・修正した2件の事故(いずれもマージ前に検出、コード修正済み)

新しいキーワードを機械的に追加しただけでは、既存の正しいMMA判定を壊す事故が2件発生した。全993試合中、旧44件の「その他」以外の960試合についても差分ゼロを確認する過程で発見した(黙殺していない):

1. **「RIZIN MMAチャレンジルール」(三浦孝太 vs YUSHI、RIZIN.33、2021-12-31)**: `MMA`という文字列と`チャレンジルール`という非MMA語の両方を含む実在の表記。単純な非MMA語一致だけだと、既存の正しいMMA判定(旧ロジックで"MMA"と判定済み)を壊してMMAでなくなってしまう。**修正**: "MMA"の明示チェックを非MMA語チェックより先に行う(手順2で反映済み)。あい×川村虹花の「RIZIN チャレンジ ルール」には"MMA"が無いため、この優先順位変更後も正しく除外されたままであることを確認済み。
2. **「憂也 vs 田中STRIKE雄基」(RIZIN.16、キックボクシングの誤字「キックボクシグ」)**: 当初のパターン`/キックボクシング/`は正しい表記のみに一致し、誤字表記に一致しなかったため、この試合が誤ってMMAに分類されかけた。**修正**: パターンを`/キックボクシ/`(「ング」を必須にしない)に緩めて誤字を許容。

いずれも実装した瞬間ではなく、全960試合の差分ゼロ確認によって検出できた(検証を先に組んでいなければ見逃していた)。

さらに「チャレンジルール」パターン自体も、あい×川村虹花戦の実際の表記「RIZIN **チャレンジ ルール**」(チャレンジとルールの間に空白あり)に初回実装が一致せず、この1件も一時的にMMAへ誤って流れていたのを同じ全件比較で検出・修正した。

### 3件の事故はいずれも「全993試合の差分ゼロ確認」という検証手順そのものによって発見された。手順を端折っていれば見逃していた。

## 3. `applyRizinRecordsToHistory()`側のdenylist(#244)との重複整理

`rizinRecordsOverride.ts`の独自denylist(`CONFIRMED_NON_MMA_RULE_TYPES`)を廃止し、`rizinScraper.ts`が公開する`NON_MMA_RULE_TYPE_LABELS`(`NON_MMA_RULE_PATTERNS`のラベル全体+`その他`)を直接importして使うよう統一した。判定基準は`rizinScraper.ts`の1箇所にのみ存在する。

超RIZIN.2のパトリッキー・ピットブル×ホベルト・サトシ・ソウザ戦のピンポイント訂正(`RIZIN_RECORDS_RULE_TYPE_OVERRIDES`)は、反転後は一般ロジックだけで自動的に`MMA`になる(実際の表記「ユニファイドルール」に非MMA語が含まれないため)ため**冗長化した**が、実害が無い(同じ"MMA"を再代入するだけ)ため削除はしていない。コメントで冗長化した旨を明記した。

## 4. 「その他」の扱い

**`parseRuleInfo`からは"その他"を生成しなくなった**(反転後は非MMA語に一致しない非空テキストは全てMMAとして扱われるため)。型定義上は引き続き有効な値として残しているが、これは手動書き起こし(`rizinRecordOverrides.ts`)側が将来「非MMAだが具体的な分類語を割り当てたくない」と判断した場合にのみ使う想定で、現状そのような使用例は無い。実測: 全993試合を再生成した結果、`ruleType`分布は以下のとおり(`その他`は0件)。

| ruleType | 件数(反転前) | 件数(反転後) |
|---|---|---|
| MMA | 777 | 789 |
| キックボクシング | 148 | 153 |
| その他 | 44 | **0** |
| unknown | 28 | 28 |
| スタンディングバウト | (新設) | 9 |

| ベアナックル | (新設) | 3 |

※合計試合数は反転自体とは無関係にRIZIN.2手動書き起こし追加(#243)分の差で1004→993ではなく、監査時点(#246、1004件)と本反映時点(#243/#244マージ後、993件)でベースが異なるための差(RIZIN.2追加+13、他の変動-24が主因。ruleType再分類による増減ではない)。

### 44件全件の期待値との突き合わせ(実測)

PR #246の分類(44件)と実装後の`ruleType`を1件ずつ突き合わせた結果、**フロイド・メイウェザー vs 那須川天心(RIZIN.14)の1件を除く43件が完全一致**した。

**例外1件の詳細**: この試合はRIZIN公式ページ側のHTML自体に`<!-- ［ルール調整中］<br> -->`というコメントが埋め込まれており(試合当日までルール調整中だったことを示す注記と見られる)、既存の`stripTags`実装がこのコメント内のネスト`<br>`タグに引きずられて誤動作し、`ruleLineRaw`が実際のルール文言ではなく`"-->"`という残骸になっている。これは今回の反転ロジックとは無関係な、既存のHTMLコメント処理の別バグであり、本タスクのスコープ外として修正していない。**実害はゼロ**(この試合の両選手(フロイド・メイウェザー・那須川天心)はいずれも自社DBのslugに未解決のため、戦績集計に一切影響しない)。
