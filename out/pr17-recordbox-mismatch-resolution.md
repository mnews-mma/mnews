# PR-17: recordbox不一致161人の決着

## 1. 真の不一致21人の全件調査結果

**分類基準を「Wikipedia recordboxの自己申告総数」から「記事自身が実際に列挙している試合数
(article_fight_cont_count)」に厳密化した。** PR-16時点の判定(`article_fight_cont_count >=
wiki_total - 2`という±2件の緩い閾値)では、記事の集計テンプレート(recordbox)自体が
実際の列挙数より多い値を自己申告しているだけのケース(140人分、パイプラインのバグではない)
と、真にパイプライン側で取りこぼしているケースの境界が曖昧だった。`prod_total <
article_fight_cont_count`(productionが記事自身の列挙数より少ない)という厳密な基準に
差し替えて再分類したところ、**真の不一致は161人中12人にまで絞り込めた**。

### 発見・修正した根本原因(1件、広範囲に影響)

**同一相手との再戦(rematch)を誤って重複と判定するバグ**が`ingest_wikipedia.py`の
`dup_fallback_match`(相手名一致、日付は問わない)に存在した。このフォールバックは
本来「Wikipedia側の行に日付が無く、日付で比較できない」場合の代替手段として設計された
ものだが、実装は日付の有無を問わず常に実行されており、公式ソースに同じ相手との別の対戦が
1件でもあれば、日付が明らかに異なる行でも「重複」として静かに破棄していた。

実例(上原誠 vs 高萩ツトム): 2010年4月3日の敗戦と2016年6月24日の勝利という2試合が
Wikipedia記事にあったが、公式K-1サイト側には2016年の分しか登録が無く、
相手名一致フォールバックが2010年の行を「2016年の試合と同一」と誤認して破棄していた。

**修正**: `fr["date"]`が存在する行には、この日付無視フォールバックを適用しないよう
ガードを追加(日付が無い行のみ適用)。

**影響範囲(機械的に全件洗い出し済み)**: この修正により以下5人で計8試合を回収した:
- 上原誠(+1試合、2010-04-03 高萩ツトム戦)
- 拳士浪(+2試合)
- 皇治(+1試合)
- HIROYA(+4試合)

修正後、`dup_fallback_match`の発生件数は75件→2件に激減(残る2件は本当に日付の無い行での
正当な適用)。同時に`held_ambiguous`(複数候補で保留)も10件→0件に減少した
(日付があれば重複判定に回されなくなったため、判定不能になるケース自体が消えた)。

### 名寄せ未解決の個別解決(1件)

`龍聖`はRISE所属(TEAM TEPPEN)とKNOCK OUT所属(BRAID/TEAM SUERTE)の同姓同名2レコードが
存在し、母集団構築スクリプト(`build_coverage_population_v2.py`)がfighters.json内の
並び順で先頭のレコード(RISE)を機械的に選んでいたため、Wikipedia記事の本人
(インフォボックス`|team=BRAID/TEAM SUERTE`と明記)と異なるレコードに紐づいていた。
インフォボックスのteam欄で個別に確認し、`DISAMBIGUATION_OVERRIDES`辞書で明示的に
KNOCK OUT側のレコードへ紐づけ直した(母集団全体で同種の曖昧な名前は3件のみ確認: 銀次・
海人・龍聖。銀次・海人はインフォボックスにteam欄が無く機械的には未解決、記録のみ)。

### 残る「真の不一致」12人(厳密基準でも解決せず)

個別調査の結果、**全12人が「同日に別表記(スペル違い)の相手名で既に正しく掲載済み」**
であることを確認した(欠落ではない)。例: シナ・カリミアン vs 木村大地(Wikipedia表記)/
木村 太地(K-1公式表記、スペース挿入の違いのみ)。これは記事の相手名表記(カタカナ変換・
スペース有無等)が公式ソースと微妙に異なるために、単純な文字列一致による診断スクリプト
(本PRで作成した`pr17_diagnose_gaps.py`)が「一致しない行」として拾ってしまうだけで、
production側には該当試合が(公式ソース経由で)正しく反映されている。**データの実害はない。**

**結論: 161人の不一致は、真の欠落0件・記事側の制約(recordboxが列挙数を上回る自己申告)
144人・相手名表記の差異による診断上の誤検知12人・名寄せ誤りとして個別解決1人(龍聖)
に完全に分類できた(残余ゼロ)。**

## 2. 140人分類の妥当性検証(無作為抽出20人)

「記事側の記載が元々不完全」と分類した144人(再分類後の件数)から無作為に20人を
抽出し、`prod_total`と記事の実際の列挙数(`article_fight_cont_count`)を個別比較した。

| 検証項目 | 結果 |
|---|---|
| production件数 ≧ 記事の列挙数(想定どおり) | **20人中20人**(uniformly確認) |
| うちproductionが記事の列挙数を上回る(公式ソースからの追加分あり) | 4人(長崎秀哉・ミゲール・トリンダーデ・カリム・ベノーイ・裕樹) |
| うちproductionと記事の列挙数が完全一致 | 14人 |
| 特殊ケース(名前が統合済みのため母集団側の古い名前で参照不能) | 1人(クンタップ・ウィラサクレック→クンタップ・チャロンチャイに統合済み、既知のPR-15/16remap事象) |
| 特殊ケース(記事に列挙が0件、recordboxのみ) | 1人(ジョムホート・キアタディサック、wiki_total=240だが列挙0件) |

**与座優貴のような隠れたパイプライン側の原因は、この20件のサンプルからは検出されなかった。**
140人分類(記事自体の制約によるもので取得不能)は妥当と判断する。
