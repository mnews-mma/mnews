**想定どおりの実態が数字で確認できた**:

- **DEEPは2012年以前が疎**。2007〜2012年の6年間で合計161bout(年平均27件)
  なのに対し、2013年以降は年間100〜250件超まで急増する。2009年は
  **0件**(この年のDEEP大会は現行`deepRecords.json`に1件も収録されていない、
  [[c-type-deep-numbered-mainline-wayback-check]]で調査した2009年のGeeklog
  CMS世代の実在確認未了と符合する)。
- **修斗は2012-12-24以降のみ**。それ以前の期間は`shootoRecords.json`(公式
  アーカイブの機械取得)には1件も無い。ただしユーザー指摘のとおり、
  「プロフィール由来の古い分」は別レイヤー(`fighterRecordFromResults.ts`
  経由でWikipedia戦績表から個別選手単位に組み立てる分)に存在し、この
  ファイル単体の集計には表れない(スコープ外のため本レポートでは未集計)。
- **パンクラスが最も収録期間が長く(1993年〜)、かつ疎密の差が最も小さい**。
  1993年時点で既に年21件、2000年代通じて年80〜140件台を維持しており、
  DEEPのような「特定年がほぼ空白」という現象は見られない。
- **RIZINは2015年12月(旗揚げ興行)〜**。PR #367マージにより2015-12-29
  (SARABAの宴)からの収録になった(マージ前は2016年〜だった)。

## d) /methodology/records ページの文面案

現行ページ(`src/app/methodology/records/page.tsx`)の収録期間表は以下:

| 団体 | 収録期間(現行) |
|---|---|
| RIZIN | 2016年〜 |
| DEEP | 2002年〜 |
| パンクラス | 1993年〜 |
| 修斗 | 2012年〜 |

上記の実データと突き合わせると、**RIZINとDEEPの2行が実態と食い違っている**:

- RIZIN「2016年〜」は、PR #367(2015年SARABAの宴・IZAの舞追加)より前の
  記述のまま更新されておらず、既に古い(実際は2015年12月〜)。
- DEEP「2002年〜」は、2002年からの大会が実在すること自体は誤りではないが
  ([[c-type-structural-gap-71-scale-measurement]]でDEEPフューチャーキング
  トーナメント2002のページ実在は確認済み)、**実際に`deepRecords.json`に
  収録されているboutは2007年からで、しかも2012年まではごく少数**という
  実態を読者に伝えられていない。「2002年〜」とだけ書くと、2002〜2011年の
  選手も2016年以降の選手と同程度に網羅されているかのように読めてしまう。

### 修正案(注記文、表の直後に追加)

```
DEEPは2012年以前の収録大会数が少なく、特に2009年は収録0件です。この時期に
主に活動していた選手は、実際の戦績よりも4団体通算が少なく表示されることが
あります。
```

書き換えずに済む表現):

```
収録期間内であっても、団体・年代によって収録できている大会数には差があります。
特に古い年代は、公式サイトのアーカイブ自体が薄い、または現在のページ構成と
異なるために取得できていない大会があります。
```
