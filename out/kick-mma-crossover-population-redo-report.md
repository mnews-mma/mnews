## 5. 判定できなかった行(件数と理由)

母集団13,727行のうち、Track A(255行)・Track B(547行、うち2行はTrack Aと重複)で
機械スクリーニング+個別確認を行ったのは合計800行。

**残る12,927行は個別の一次資料確認を行っていない(未判定)。**

理由:
- mnewsが保有する4種の構造化MMA戦績DB(RIZIN/DEEP/PANCRASE/SHOOTO)いずれにも該当bout
  (日付+選手名+対戦相手)が見つからない
- 大会名がRIZIN/DEEP/PANCRASE/修斗/Bellator/PRIDE/巌流島/ONE/GRACHAN/HEAT/ZST/GLADIATORの
  いずれのパターンにも一致しない
- 上記12,927行のpromotion(データ取得元)内訳: Wikipedia(その他団体)4,192 / RISE 2,127 /
  K-1・Krush・Krush-EX 1,022 / KNOCK OUT 975 / NJKF 935 / 全日本キックボクシング連盟 544 /
  Bigbang 496 / KROSS×OVER 467 / SHOOT BOXING 448 / HoostCup 439 / GLORY 236 /
  IT'S SHOWTIME 222 / NKB 171 / ルンピニー(タイ・ムエタイの聖地) 145 / WAKO SuperLeague 139 /
  ラジャダムナン(同) 120 / Thai Fight 74 / JKA 60 / ONE Championship 32(既にTrack Bで
  代表確認済みの残余分) / 新日本キックボクシング協会(SNKA) 30 / DEEP☆KICK 24 / 武林風 20 /
  Stand up 9 / EM Legend(中国発ムエタイ/キック団体、確認済み) 5 / RIZIN 1(#597で既に
  低リスクと確認済みの重複行) / J-NETWORK 1
- 上記のうち7,777行(全体の60%)は、その立ち技専門団体自身の公式サイトを直接の取得元
  (promotion欄)としており、その団体自身が自らのキックボクシング/ムエタイ記録として掲載している
  という状況証拠がある。残る大半(4,192行、Wikipedia(その他団体)経由)は個別の出典記事を1件ずつ
  確認しないと確定できない
- 12,927行全件についてWeb一次資料での個別確認を行うことは、本PRの現実的なスコープを超える
  (小規模・地方・海外の立ち技団体が多数を占め、件数が#597の344件・本PRのTrack A/Bの800件と
  比べて桁違いに大きい)

この12,927行は本PRでは除去せず、現状維持する。ユーザー指示により**他競技混入監査はこのPRで
打ち切り**とし、以後のフォローアップは行わない。残存リスクとして記録するのみ。

## 8. 本PRのスコープ外で新たに見つかった問題(着手せず記録のみ)

- KROSS×OVER CAGE.6の大会日付について、kick DB側は「2025-07-13」だが、KROSS×OVER公式ブログの
  同カードの発表記事は「6/15 KROSS×OVER CAGE.6」としており、日付に食い違いの疑いがある
  (今回のKICK PART/MMA PART判定には影響しないため深掘りしていない)。
- HEAT・GLADIATORの一部行(GRACHAN11・12のMIKE JOE、GLADIATOR 6/13の横山伸吾等)は、
  個別の一次資料に直接到達できず、団体の一般的傾向(「キックボクシングルール」明記が支配的)からの
  推定にとどまっている。将来的にこれらの一次資料が見つかった場合は再確認が望ましい。
- 母集団再構築時、SAFE_PATTERNS(自社興行名パターン)に「全日本キックボクシング協会/連盟」が
  含まれておらず(「新日本」のみ登録されていた)、544行が本来なら機械的に安全側へ分類できたはずが
  未分類のまま個別判定不要リストに残った。判定結果自体には影響していない(既に安全と結論済み)が、
  将来同種の監査を行う場合はパターンの見直しが望ましい。
- **未判定12,927行の中の具体例**: 除去対象になった浅野功暉のページを実機確認した際、除去後も
  残る2行のうち1行が「WARDOG CAGE FIGHT 50」(2024-10-27、大阪)だった。Web一次資料
  (fighters-spirits.com)を確認したところ、浅野功暉自身の対戦(vs 輝也)についてはルール表記が
  確認できなかったが、**同一カードの他カードでは「ツイスターサブミッション」等の関節技による
  決着が複数報告**されており、大会名の「CAGE」表記とあわせてMMA(総合格闘技)の可能性がある。
  この一戦は12,927行の未判定分に含まれており、今回は個別追跡していない(着手せず記録のみ)。
  同種の「CAGE」を含む地方系大会名が他にも未判定行の中に存在する可能性が高い。
