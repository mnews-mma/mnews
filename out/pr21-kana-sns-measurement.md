# PR-21: 読みのSNS経路(まず測定)

## 結論(先出し)

**SNS経路によるかな取得は、無作為8件の実測で取得率0%(0/8)となり、明確に低い結果が
出たため、指示どおりここで打ち切った。672件への全件展開は推奨しない。** データ変更は
行っていない。

## 1. かな充足率の実測(再測定)

PR-15〜PR-20で選手数・かな充足済み数に変化が無いことを確認した。

| 項目 | 値 |
|---|---|
| 収録選手数 | 3,300人 |
| かな充足済み | 2,401人 |
| **かな充足率** | **72.76%**(コーディネーター記載の見込み73.3%とは別測定、PR-15完了時点から不変) |

PR-16〜20はいずれもWikipedia/ONE公式取得・欠落調査・小欠陥修正が中心で、かなフィールド
自体への変更を伴う作業が無かったため、この期間で数値は変動していない。

## 2. 対象母集団の特定

「曖昧672件」は`out/kana-romaji-leg1-candidates.csv`(726件、`classification`列で
分類)の`曖昧`区分と一致することを確認した(与座優貴の確定1件を除いた672件、
`out/kana-leg2-report.md`の記述と整合)。この672件を現行の名簿(3,300件、PR-15〜17の
統合修正反映後)と突合したところ、**632件が現行名簿にも存在し、かな未取得のまま**
であることを確認した(40件は統合により対象外になったか、既にかな取得済み)。

## 3. SNS経路の無作為抽出測定(n=8、100件から早期打ち切り)

`out/kana-romaji-leg1-candidates.csv`の該当632件から`random.seed(42)`で無作為100件を
抽出したが、**実際に検証したのは先頭からの8件のみ**で打ち切った。理由は下記4節のとおり。

### 測定手法

各選手について、氏名+所属団体名+「Twitter」「X」「Instagram」「読み方」等のキーワードで
Web検索を実施し、以下の採用条件で判定した:
- 本人アカウントのプロフィール欄にひらがな・カタカナ表記があるか
- 団体公式アカウントが本人特定できる形でタグ付けしている投稿があるか
- 上記以外(第三者まとめサイト・ブログ・AIによる推測読み)は**不採用**

## 4. 早期打ち切りの判断根拠

以下の**構造的な理由**により、追加92件を検証しても同様の結果になる可能性が高いと判断し、
指示(「取得率が低ければここで打ち切ってください」)に従い8件で測定を終了した:

1. **利用可能な検索ツールの制約**: 本セッションで利用できるWeb検索ツールは検索エンジンの
   索引結果を返すのみで、個別のX/Instagramアカウントのプロフィール欄本文を直接閲覧する
   機能を持たない。ヒットするのはほぼ例外なく団体公式アカウント・無関係な同姓同名
   アカウント・第三者まとめサイトのいずれかで、8件全てがこのパターンに該当した。
2. **採用条件の厳格さとの相性**: コーディネーター指定の採用条件(本人アカウント本文
   または団体公式タグ付け投稿に限定、同姓同名の誤採用防止)は妥当だが、この条件を
   満たす検索結果自体が本ツールでは実質的に得られなかった。
3. **AIによる推測読みの混入リスク**: 8件中1件(中島将志)で検索結果の要約が「漢字から
   読みを推測」する形で回答を生成しており、これを無批判に採用すると本プロジェクトが
   最も警戒している「推測によるかな捏造」を誤って持ち込むリスクがある。この種の
   誤検知が発生しうること自体が、このアプローチの信頼性に対する追加のマイナス材料。
4. **CLAUDE.mdの利用量管理方針との整合**: 「トークン消費が大きい作業は対象を絞る・
   サンプリングする」方針に基づき、明確な負の傾向(8/8不採用)が出た時点で残り92件を
   機械的に消化することは非効率と判断した。

## 5. 672件全件展開の可否

**展開しない(推奨)**。 実測(n=8)で取得率0%、かつ構造的な理由(検索ツールの機能制約)
により件数を増やしても改善が見込めないため、SNS経路によるかな充足の全件展開は
費用対効果が見合わないと判断する。
