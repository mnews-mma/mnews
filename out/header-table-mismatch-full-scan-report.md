# ヘッダーと対戦テーブルの数字食い違い全数把握(指示書L)報告

生成日時: 2026-08-04(JST)。read-only(投入・修正は一切行っていない)。

## 前置き: tamura-hibikiの現状

指示書で例示された`tamura-hibiki`(ヘッダー9-11-5・テーブル1試合)を確認したところ、
**現在は既に解消されていた**。現在のデータでは`fighter.wins/losses/draws`が
1-0-0・`needsReview:true`・`live:false`のため`shouldPreferMultiOrgRecord()`が
常時true(2行目採用)を返し、ヘッダー・テーブルとも4団体合算(9-11-5)に
揃っている。指示書作成後にneedsReviewフラグの付与か関連ロジックの変更で
解消されたとみられる(本調査では原因追跡はしていない)。

**ただし同種の食い違いは別に49名で現存していた**ため、以下に全数報告する。

## 4. 表示行(1行目/2行目)別の影響の出方

**明確に異なる。**

- **2行目(4団体合算)表示の11名**: 全件が`table_more_nc_explained`(NC説明可能)。
  内訳完全一致でNC分だけ多い、という設計通りの状態のみで、**真の食い違いは
  1件も無い**。ヘッダー(`computeMultiOrgRecord`)とテーブル
  (`computeMultiOrgBoutTable`)は同一の4団体データから同時に計算されるため、
  NC以外で食い違う余地が構造的に無いことが確認できた(指示書R-9の設計が
  2行目側では正しく機能している)。
- **1行目(Wikipedia通算)表示の38名**: 29名はnc説明可能(実質問題なし)、
  **残り9名が真の食い違い**。原因はWikipedia記事自体の内部不整合
  (infobox集計値とrecordbox表の不一致)であり、mnews側のロジックの問題
  ではなく元データの問題。

## 5. 表示方針の選択肢(実装はしない、影響件数付き)

### 案A: 1行目でも常に4団体bout(computeMultiOrgBoutTable)からテーブルを組む

**非推奨。** 実行可能性を確認するため、真の食い違い9名のうち`sumimura-ryuichiro`
(shooto)・`seki-tetsuya`(deep)について4団体データ側の実際の捕捉状況を
確認したところ、`computeFighterShootoRecord()`は6bout(3-4-1)、
`computeFighterDeepRecord()`は4bout(2-2-0)しか無く、**いずれもWikipedia側の
テーブル(19-26件)より大幅に少ない**。4団体データは1行目対象選手(通常
Wikipedia経由でRIZIN以外の団体・海外含む生涯戦績を持つ)にとって、
そもそも生涯戦績のごく一部しか捕捉していないため、この案を採用すると
**大多数の1行目選手でテーブルが現状より大幅に薄くなる**(UFC/ONE等
4団体外の戦績が丸ごと消える)。9件の解決にもならない。

### 案B: 1行目(history)と4団体bout(multiOrgBoutTable)をマージする

**効果が薄いと判明。** 上記の実測の通り、4団体データは真の食い違い9名の
不足分を埋めるほどの量を持っていない(sumimura-ryuichiroの不足10件に対し
shooto側は6件全体、seki-tetsuyaの不足2件に対しdeep側は4件全体で該当日
との一致は未確認)。マージ実装の複雑さ(日付+対戦相手の重複排除ロジックが
必要)・二重計上リスクに見合う効果が無いと判断する。

### 案C: `historyReconciles()`が偽になる選手はテーブルを注記/非表示にする(推奨候補)

**真の9名のみに影響が限定される。** 既存の`historyReconciles()`
(勝敗分の内訳一致のみを見る、nc等は対象外)は、40件のnc説明可能ケースを
「一致」として通し、真の9件だけを「不一致」として検出することを確認済み
(butterflyチャートの非表示判定に既に使われているのと同じ関数・同じ基準)。
この判定をテーブル表示にも適用する(例: 「対戦テーブルは現在準備中」の
注記付き非表示、またはヘッダーと同じ数値に揃うまでテーブルを出さない)ことで、
**既存のチャート非表示ロジックと完全に一貫した状態**にできる。新規の
データ取得・マージロジックは不要で、既存関数の適用範囲を広げるだけの
変更で済む。影響は真の9名のみ(全365名中2.5%)。
