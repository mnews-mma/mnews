# 修斗公式アーカイブ(shooto-mma.com) 出場選手データ信頼開始年の確定調査

読み取り専用調査。`data/`・`src/` は一切変更していない(git diffゼロ)。新規の本文パース正規表現は書いていない(目視判定+原文抜粋のみ)。

## 結論(最重要)

**信頼できる開始年 = 2012年(アーカイブ最古のイベント、id=26「VTJ 1st」2012-12-24)。**

`https://www.shooto-mma.com/result/?id=N` の各大会ページには、必ず「試合結果 概要」という見出しの構造化セクションが存在し、そこに以下の定型フォーマットで個別対戦結果が入っている。このフォーマットは **2012年から2026年(直近サンプル)まで一貫して同一構造** であり、DEEP公式サイト調査(PR #231/#232)で見られたような「2024年以降のフォーマットにしか対応できない」的な断絶は見つからなかった。

```
[大会内呼称(メインイベント/セミファイナル等・任意)]
第N試合 [階級] [ラウンド仕様]
[選手A氏名] [所属ジム] [VTJ戦績|SHOOTO戦績|グラップリング戦績 X戦 Y勝...] [計量結果:...(2018年以降の大会で頻出)]
[選手B氏名] [所属ジム] [同上]
[ラウンド数] [判定/KO/TKO/S(サブミッション)等] [タイム] [決まり手]
［レフェリー］[氏名] ［サブレフェリー／ジャッジ］[採点]
```

差分は「VTJ戦績」(2012〜2015年、VTJ=バーリトゥード・ジャパン系イベント)か「SHOOTO戦績」(2016年以降、修斗系イベント)かのラベル違いと、「計量結果」フィールドの有無(2018年前後から追加)程度で、選手名・階級・体重・勝敗記号・KO/S/判定・ラウンド/タイム・決まり手はすべて2012年時点から一貫して人間の目で読み取れる。

**停止条件はいずれも非該当**(後述)。

## 手順1: 結果一覧(`/result/`)の列挙

`https://www.shooto-mma.com/result/` を取得(1回)。1ページに全228行の大会が列挙されている(想定どおりページネーションなし)。日付範囲は2012-12-24(VTJ 1st)〜2026-07-20(PROFESSIONAL SHOOTO 2026 Vol.5、id=254)。

- 228行のうち226行は `href="./?id=N"` の形でクリック可能なリンクを持つ。id番号の範囲は1〜299。
- 残り2行は**日付・大会名は表示されているがリンク(id)が欠落**している行だった:
  - `2016-09-04 BORDER-season8-「The2nd」`(会場欄も空)
  - `2017-03-19 BORDER-season9-「The1st」`(会場: 大坂市平野区/コミュニティプラザ平野)

この2件について、id=27・id=40 に直接アクセスしたところ、それぞれ日付・大会名が完全一致する**個別対戦結果付きの実データ**が存在した(下記「id欠番の実態」参照)。つまり一覧ページ自体には両大会の存在が(リンクなしで)表示されているが、マークアップ上のリンク欠落によりクロール時に見落としやすい状態になっている。

全228行を日付順に整理したテーブルは `out/index_items_by_date.tsv` に保存(id・開催日・大会名・会場)。VTJ・BORDER・SHOOTO GIG・FORCE・闘裸男・越後風神祭り・THE SHOOTO OKINAWA・COLORS・TORAO・Lemino修斗など多数のシリーズが除外なく混在している(タスク指示どおり除外せず列挙のみ)。

## 手順1続き: idの欠番調査

一覧に現れるid(226件、範囲1〜299)に対し、範囲内の欠番(現れないid)は73件あった。うち21件をサンプリングして直接アクセスし、原因を分類した(合計リクエスト数は本調査全体で約40件、100件の停止条件には遠く及ばない)。

| 分類 | 該当id(サンプル) | 実態 |
|---|---|---|
| 空きスロット(未使用id) | 2, 9, 14, 15, 20, 30, 32, 49, 53, 91, 137, 210, 297 (13件) | HTTP 200・9047byte固定サイズの空テンプレート。本文は「登録されているマッチメイクはありません。」の一文のみ。大会自体が存在しない。 |
| 日程未確定の薄いスタブ | 13, 34, 186 (3件) | 13: 選手プロフィールモーダルの断片(「VTJ戦績 初参戦」)は見えるが対戦カードなし、開催日は空欄。34: 2015-11-29後楽園ホールの実在イベント(協賛・後援等の詳細あり)だが「登録されているマッチメイクはありません。」=個別結果は一件も未登録。186: 「日程未定 大阪大会」(開催日 0000年00月00日)。 |
| リンク欠落だが実データあり | 27, 40 (2件) | 27=BORDER-season8-「The2nd」(2016-09-04、大阪)、40=BORDER-season9-「The1st」(2017-03-19、大阪)。いずれも第1試合〜メインイベントまでの完全な対戦カード・勝敗・決まり手が読み取れる。上記「一覧のリンク欠落2行」と同一大会。 |
| 未来の開催予定(結果未発生) | 255, 270, 288 (3件) | 開催日が2026年9月・11月等の未来日付。会場・主催者情報のみで「結果」はまだ存在しない(開催前のため当然)。 |

**「抽出できない」と「そもそも個別結果が載っていない」の区別**(DEEP調査と同じ観点での整理):
- 空きスロット13件・スタブ3件(id=34含む)は「そもそも個別結果が載っていない」側(掲載自体がない、または開催されたが結果が未登録)。
- リンク欠落2件(id=27, 40)は「個別結果は完全に載っているが、一覧ページのクロール時に見落としやすい」という別種の問題(抽出可否の問題ではなく発見可否の問題)。
- 未来3件は正常な仕様(未開催なので結果なし)。

73件中の残り52件は未サンプリングだが、上記の内訳(空きスロットが大半)から見て、年代の偏りなくほぼ同種の「空きid/未来予定/リンク欠落」に収まると推測される(悉皆調査はスコープ外)。

### 補足: ページ内に混在する「関連情報」記事との混同に注意

各イベントページには「試合結果 概要」の構造化セクションとは別に、**「関連情報」という見出しの下に、記者が書いた前日計量レポートや当日の速報記事(ナラティブ形式・○/×の勝敗記号・短いコメント文つき)が複数本、日付降順で並んでいる**ことが多い(特に2017年・2025年・2026年のサンプルで顕著)。この「関連情報」記事は年によって文体・詳細度が異なり(いわば人間向けの読み物)、一見すると「年によってフォーマットが変わっている」ように見えるが、これは構造化データではなく付随記事である。**構造化された「試合結果 概要」セクション自体は全年で同一パターンを保っている**。これは今回の調査で最初に誤認しかけたポイントであり(DEEP調査の教訓どおり、機械的な位置だけで判断せず本文を最後まで確認して訂正した)、将来この一覧を機械的に扱う場合は「関連情報」記事と「試合結果 概要」を混同しないよう注意が必要。

### フォーマットの種類数

構造化データとしては実質1系統(記録ラベルが「VTJ戦績」→「SHOOTO戦績」に変わる、「計量結果」フィールドが2018年前後から追加される、稀に「グラップリング戦績」も出現する、という程度の差異)。10種を超える断絶は見られなかった(停止条件非該当)。

## 手順6: 選手紹介ページのURL構造

`https://www.shooto-mma.com/fighters/?pg=fighters&weight_class=1` を取得。階級一覧ページ内の個別選手詳細へのリンクは `./?id=1007` のような**数値id**形式であり、選手名のローマ字表記はURLに含まれていない。名簿抽出そのものは別指示書のスコープのため、ここではURL構造の確認のみで留めた。

## 停止条件の該非

- 本文フォーマットが10種を超えた → **非該当**(実質1系統、ラベル・フィールドの軽微な差異のみ)
- 「信頼できる開始年」が2024年より新しい → **非該当**(2012年、アーカイブ最古の大会まで遡って読み取り可能)
- サンプリングが100件を超える必要が生じた → **非該当**(index取得1件+id欠番サンプル21件+年別サンプル15件+id=1確認1件+fighters確認1件 ≒ 39件)
