# Wikipedia自動一致11名の同名別人判定(読み取り専用)

生成日時: 2026-07-28(JST)
対象: #252(`feat/roster-injection-94`)で投入した92名。
手法: `src/lib/feeds/resolveFighter.ts` の `resolveFighter()`(ライブWikipedia解決。`data/`への書き込みは一切発生しない純粋fetch関数)を92名全員に直接呼び出し、`live:true`(Wikipedia記事が自動一致)となった選手を特定した。`data/` 配下は不触(このスクリプト自体がfs書き込みを持たない)。

**本レポートは数字を出すところまで。同名別人の断定・修正はしていない。**

## 停止条件チェック

- 自動一致した選手数: **11名**(想定どおり。11名でない場合は停止する条件だったが該当せず)
- Wikipedia側historyが取得できなかった選手: **0名**(該当せず)

## 手法の詳細

- 投入history(#252で `src/lib/fighters.ts` に格納したarchive集計由来のhistory)の対戦相手名リストと、`resolveFighter()` がWikipediaから取得したhistoryの対戦相手名リストを突き合わせた。
- 表記ゆれの吸収は **NFKC正規化 + 空白(全角/半角)除去** のみ(指示書どおり。それ以外の表記ゆれ(異体字・送り仮名等)は吸収していない=未一致に含まれる可能性がある)。
- 包含率 = 投入bout中、対戦相手名がWikipedia側historyに(正規化後)存在した件数 ÷ 投入bout総数。
- 「一致しなかった相手名」は投入side(archive集計)の対戦相手名で、Wikipedia側historyに正規化後一致が無かったもの(表記ゆれ由来の可能性と、真に該当試合がWikipedia記事に無い可能性の両方を含む。本レポートでは切り分けていない)。

- 包含率100%の5名(青野ひかる、SARAMI、藤野恵実、山木麻弥、杉山しずか)は、投入bout(archive集計)の対戦相手が全件Wikipedia側historyにも(正規化後)存在した。
