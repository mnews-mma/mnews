# パンクラス公式選手インデックス 名寄せ辞書(指示書H)

**種別**: 調査のみ(read-only)。`data/` は無変更、alias登録は行っていない。出力はすべて `out/` 配下。
**位置づけ**: 指示書D(null-slug突合)への追加インプット。

## やったこと

1. パンクラス公式サイトの選手一覧3ページ(日本人選手1,147名・外国人選手415名・女子選手121名、計1,683件)を取得し、表示名(日本語)とURL stem(プロフィールページのファイル名)の対応表を作成した。
2. 表示名が完全一致するのにURL stemが異なるエントリ(=同名別人の可能性)を機械的に検出した。
3. 指示書Dの `out/null_slug_name_variant_hits.json` に記載された既知の名前ゆれ候補(力也/天弥/敢流)について、該当プロフィールページを個別に取得し、生年月日・出身地・所属ジムで裏取りした。

## 重要な発見:プロフィールページに「本名」欄は無い

パンクラス公式プロフィールページの構成は次の通り(全ページ共通フォーマット):

```
{英語表記}　{リングネーム(日本語)}　{所属ジム}
生年月日：yyyy年m月d日
身長・体重：###cm
出身地：##県
（タイトル歴があれば）
（戦績テーブル）
```

「本名」「読み」という独立フィールドは存在しない。**URL stem自体が実質的な本名の手がかりになっている**ケースがある(例: `yoshimuratenya.html` の表示名は「天弥」のみだが、stemには姓「吉村」が埋め込まれている)一方、姓が全く分からないケースも多い(例: `rikiya.html` の表示名は「力也」のみ、stemも`rikiya`のみで姓の手がかりが無い)。
したがって、指示書Hが依頼した「本名/読みの対応表」は、プロフィール本文からではなく**URL stemから読み取れる場合のみ**手がかりとして使える。この点を対応表に反映した(`stemHint`列は今回作成していない自動推測ではなく、個別に裏取りできたケースのみ下記に手動で記載)。

## 出力ファイル

- **`pancrase_name_reconciliation_table.json`**(1,683件): `{urlStem, href, displayName, listSource}` の全件対応表。`listSource`は `japanese` / `foreign` / `women(mixed nationality)` の3種(女子選手一覧は国籍で分離されていないため、外国籍選手も混在する)。
- **`pancrase_exact_name_collisions.json`**: 表示名が完全一致するのにURL stemが異なるエントリの一覧(同名別人の機械検出結果)。

## 指示書D関連の既知ケース裏取り結果

`out/null_slug_name_variant_hits.json` に記載された6件のうち、パンクラス公式サイトで裏取りできたもの:

### ① 天弥(pancrase, slug=`tenya`) → 吉村天弥 で一致(確度高)

- 公式stem: `yoshimuratenya.html`
- プロフィール表示: 「Tenya　天弥　和術慧舟會HEARTS」、生年月日2004年5月7日、出身地山口県
- null-slug側の対戦相手表記「吉村天弥」(NEO BLOOD! 5/3, PANCRASE 334)と一致。**stemの「yoshimura」が姓の直接的な裏付けになっている。**

### ② 力也(DEEPのDB, slug=`rikiya`) → 「辻川力也」とは別人、「川上力也」は公式サイトに不在

公式サイトに「力也」単体のエントリが独立して存在する(`rikiya.html`)。これは「辻川力也」(`tsujikawar.html`)とは**別人**と確定できる:

| | 力也(`rikiya.html`) | 辻川力也(`tsujikawar.html`) |
|---|---|---|
| 生年月日 | 1992年12月21日 | 1998年6月26日 |
| 出身地 | 長野県 | 和歌山県 |
| 所属ジム | KRAZY BEE | 創道塾 |

生年月日・出身地・所属ジムのすべてが異なり、同名別人であることが裏付けられた(指示書Hが例示した通りの結果)。
一方、null-slugのもう一方の候補「川上力也」(2004-08-22 PANCRASE 2004 BRAVE TOURの対戦相手)は、パンクラス公式サイトの現行選手一覧に該当エントリが見つからなかった(2004年当時の選手は現行サイトの掲載対象から外れている可能性がある)。**この一件は公式サイトからは裏取りできず、未解決のまま。**

### ③ 敢流(pancraseのDB, slug=`kanru`) → DEEP側表記「森田敢流」とは未確定

公式stem: `isana.html`。プロフィール表示は「Isana　敢流　パンクラス大阪稲垣組」、生年月日2003年8月25日、出身地奈良県。姓の手がかりはstem・本文どちらにも無い。
公式サイトの全1,683件を「森田」で検索したが、一致するエントリは「森田祥平」(`moritashohei.html`)のみで、「森田敢流」に対応するエントリは見つからなかった。**DEEP側の対戦相手表記「森田敢流」が本当に敢流(Isana)と同一人物かは、この調査だけでは確定できない。**(NEO BLOOD参戦選手の中には、パンクラス側では本名非公開でリングネームのみ登録される一方、他団体では本名を記載するケースがあるとみられるが、推測の域を出ない。)

## 副産物:表示名の完全一致による同名別人の追加検出

`out/null_slug_name_variant_hits.json`に無い新規ケースとして、公式サイト全体で表示名が完全一致するのにURL stemが異なる例が1件見つかった:

**泰斗**: `taito.html`(1989年8月29日生, 山梨県, KIBAマーシャルアーツクラブ) と `taitosc.html`(1990年1月19日生, 東京都, 真月流COMBAD) — 生年月日・出身地・所属ジムすべて異なり、同名別人と確定。`fighters.ts`・戦績データ内に「泰斗」という表記が絡む未解決ケースがあれば、この2名の混同に注意が必要(現時点でそのようなケースがdata/内に存在するかは未調査。指示書Dの対象範囲外のため今回は確認していない)。

## 対応表の使い方(指示書D向けメモ、実装はしない)

- URL stemに姓らしき文字列が含まれる場合(例: `yoshimuratenya`, `tsujikawar`)、それを本名の手がかりとして採用できる。
- 表示名だけでは同名別人を区別できない(`力也`/`泰斗`の例)。突合の際は生年月日・出身地・所属ジムなど、プロフィール本文の付随情報を追加の裏取り材料として使うべきで、名前の文字列一致のみで自動マージするのは危険。
- 女子選手一覧(`women(mixed nationality)`)は国籍で分離されていないため、この対応表だけでは外国籍かどうか判定できない。
